## 🎮 Como Instalar (Mobile)

### Método 1 - Via MCPACK (Recomendado)
1. Baixa os arquivos `.mcpack`
2. Abre o arquivo no Minecraft
3. O jogo importa automaticamente! ✅

### Método 2 - Via Pasta Manual
1. Extrai os arquivos
2. Copia para:
   - RP: `/storage/emulated/0/games/com.mojang/resource_packs/`
   - BP: `/storage/emulated/0/games/com.mojang/behavior_packs/`

3. Abre Minecraft e ativa os packs
